# For You — Birthday Website

## Structure
- index.html — page structure and content sections
- style.css — all styling
- script.js — all behavior + the CONFIG block (edit this to personalize)
- images/us/ — put your couple photos here
- images/food/ — put food photos here
- music/ — put your song here (song.mp3), see music/README.txt

## Before you publish
Edit the CONFIG object at the top of script.js:
- herName, navBrand, coverTitle, coverSub
- letterHeading, letterParagraphs, letterSign
- gallery.us and gallery.food (set img to "images/us/yourfile.jpg")
- memories (the 6 memory-match pairs)
- quiz questions
- song.src and song.title (the floating CD player, bottom-right)
- finaleTitle, finaleBody

## Preview locally
Open the folder in VS Code, install the "Live Server" extension,
right-click index.html > "Open with Live Server".
